# NOTE on OCR/translation: this app's primary OCR (envelope routing, letter
# transcription, Spanish-language translation) runs on Ollama, a separate
# service, NOT a pip package -- it is not and cannot be listed below. Install
# it on the host machine separately (https://ollama.com) and pull the vision
# model (`ollama pull qwen2.5vl:7b`); see docs/technical_deployment_guide.md
# ("Prerequisites") and README.md for the full setup and OLLAMA_BASE_URL /
# OLLAMA_VISION_MODEL config. `httpx` below is what this backend uses to call
# it over HTTP. `google-cloud-vision` is an optional, off-by-default cloud
# OCR fallback (OCR_PROVIDER=google_vision) for envelope routing. Letter
# *content* OCR/translation stays local-only by default too, with one
# narrow, explicit exception (added 31Aug2026): TranslateLetter.jsx's
# opt-in "Translate via Google Vision" path, which is hard-gated on the
# page being redacted first (see /transcribe-page-cloud and
# /translate-lines-cloud in api/letters.py) -- Rey's own manual fallback
# for content the local model handles poorly, done from here instead so
# the redaction gate is actually enforced rather than relied on by habit.
# `google-cloud-translate` backs that path's translation step.
